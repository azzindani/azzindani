👋 **Welcome to my GitHub profile.**

Frontier models keep arriving, and AGI has stopped being a someday question. Agentic is the concept; a harness is the vessel that carries it — and new ones land every week. Ideas that used to take a quarter now ship in a weekend.

What interests me most is the loop inside that: using AI to help AI help us. Every tool that makes an agent more capable makes the next one faster to build — and that compounds.

Which is why the bottleneck now is implementation. An agent is only as useful as what it can reach, and every domain sets its own terms: office productivity, research, scientific computing, data analysis. Each one needs tooling built for it before an agent can do anything real there.

So the aim here is meaningful tools across as many of those domains as possible, contributed openly. If something saves you from building it yourself, it has done its job.

Have a look around.
